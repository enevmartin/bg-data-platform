Step 1 — Process Files

Reads all downloaded Excel / CSV files, extracts tables, and saves them as Parquet datasets. Each sheet becomes a separate dataset record.

  • ✓ Multi-sheet Excel (.xlsx / .xls)
  • ✓ Auto-detected CSV encoding + delimiter
  • ✓ Snake_case column names
  • ✓ Saved as compressed Parquet (fast + tiny)

Step 2 — Analyze Datasets

Runs statistical quality checks on every Parquet dataset and stores the results. Unlocks quality gauge, column stats, and distribution charts.

  • ✓ Missing value % per column
  • ✓ IQR outlier detection
  • ✓ Duplicate row detection
  • ✓ Composite quality score (0–100)
